\section*{Where to start}

This folder is the Phase-1 submission. Two documents carry the work:

\begin{itemize}
  \item \textbf{technical-report-v2.pdf} (8 pages). The technical report:
  method, measured results over 3 seeds, exact Lipschitz certificates, the
  refusing runtime guard, the full safety suite, honest limitations, and a
  claim-to-artifact provenance appendix.
  \item \textbf{concept-proposal.pdf} (3 pages). The concept proposal:
  problem framing, approach, feasibility, impact, validation plan, and team.
\end{itemize}
